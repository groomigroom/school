## 1. 델파이 (하향식) 기법 기반 개발 공수 산정 결과표

* 1 M/D(Man-Day): 개발자 1명이 하루(8시간) 동안 작업하는 양
* 전문가 합의 적용 기준: Core(필수)는 즉시 구현 가능한 수준, Extension/Advanced는 연동 및 인프라 구축 공수 반영.

| 구분 | 대기능 | 상세 구현 범위 | 전문가 합의 공수 (M/D) |
|---|---|---|---|
| Core (필수) | 회원 관리 | 회원 등록/수정/탈퇴, 상태 관리, 만료일 자동 계산 | 5 M/D |
| | 회원권 상품 관리 | 기간제/횟수제 상품 등록, 양도, 락커/운동복 부가서비스 | 7 M/D |
| | 결제 및 매출 관리 | 수단별 매출 기록, 환불/미납 관리, 일간/월간 통계 UI | 8 M/D |
| | 출석 및 입장 관리 | 번호/QR 출석 체크, 입장 제한, 잔여 횟수 자동 차감 | 6 M/D |
| Extension (확장) | PT/수업 예약 | 트레이너 스케줄러, PT 예약/취소, 대기자, 횟수 차감 | 12 M/D |
| | 알림톡/SMS 연동 | 카카오 알림톡/SMS API 연동, 조건별 자동 발송 로직 | 4 M/D |
| | 인바디 데이터 연동 | 인바디 오픈 API 연동 또는 수동 입력 화면, 변화 그래프 | 7 M/D |
| Advanced (고도화) | 회원 전용 웹/앱 | 회원 로그인, 남은 회원권 확인, 직접 예약, 바코드 입장 | 18 M/D |
| | 키오스크 & IoT | 비대면 결제 연동, 출입문 락 제어 하드웨어/API 연동 | 15 M/D |
| | 대시보드 & 분석 | 재등록률 통계 데이터 시각화, 장기 미출석자 추출 알림 | 8 M/D |
| 공통 | 인프라 및 테스트 | DB 설계, 서버(AWS 등) 구축, 통합 테스트 및 검수 | 10 M/D |
| 합계 | | 총 개발 공수 | 100 M/D |

## 💡 예산 조율을 위한 전문가 제언 (Actionable Momentum)
만약 초기 예산 부담이 크시다면 델파이 전문가 그룹은 "단계별 분할 발주"를 권장합니다.

* 1차 계약 (Core + Extension 일부): ₩15,000,000 ~ ₩18,000,000 선에서 헬스장 기본 운영 및 PT 예약을 먼저 오픈합니다.
* 2차 계약 (Advanced): 실제 회원 수가 늘어나고 무인화가 필요한 시점에 모바일 앱과 키오스크 연동을 추가 개발하는 것이 리스크를 최소화하는 방법입니다.
