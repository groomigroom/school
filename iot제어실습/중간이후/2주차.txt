ATmega128A의 기준 전압을 5V로 사용하는 이유는 일반적으로 ATmega128A를 구동하는 전원 전압(VCC)을 5V로 설정하기 때문이야.

다만, 정확하게는 ATmega128A의 기준 전압이 무조건 5V인 것은 아니야.

### 1. 5V를 사용하는 이유

1. 전원 공급 전압(VCC): ATmega128A는 5V 전원으로 구동할 수 있어.
2. 디지털 신호 기준: 5V를 공급하면 HIGH 신호는 일반적으로 5V에 가까운 전압으로 표현돼.
3. ADC 기준 전압: 아날로그 입력값을 디지털 값으로 변환할 때 5V를 기준으로 사용할 수 있어.

### 2. ADC에서 5V가 의미하는 것

ATmega128A의 ADC는 10비트이므로 총 1,024단계(0\~1023)로 전압을 구분해.

기준 전압을 5V로 설정하면 다음과 같아.

| 입력 전압 | ADC 변환값 |
| ----- | ------- |
| 0V    | 0       |
| 1V    | 약 205   |
| 2V    | 약 409   |
| 3V    | 약 614   |
| 4V    | 약 818   |
| 5V    | 1023    |

계산 공식은 다음과 같아.

\\[ ADC=\frac{V\_{in}}{V\_{ref}}\times1023 \\]

### 3. 핵심 정리

- VCC: 마이크로컨트롤러에 공급하는 전원 전압
- AVCC: ADC 및 아날로그 회로에 공급하는 전원
- AREF: ADC 변환의 기준 전압
- ADC: 아날로그 전압을 0\~1023의 디지털 값으로 변환

시험에서 기억할 내용!

ATmega128A는 10비트 ADC를 사용하므로 기준 전압이 5V라면 1단계당 약 4.88mV의 전압 차이를 구분할 수 있어.

\\[ \frac{5V}{1024}\approx4.88mV \\]

즉, 5V를 1,024단계로 나누어 측정하는 거야!

대부분의 산업용 센서가 4\~20mA 전류 신호를 사용하는 이유는 외부 노이즈에 강하고, 장거리에서도 정확하게 측정값을 전달할 수 있기 때문이야.

핵심 이유는 5가지야.

### 1. 노이즈(전기적 잡음)에 강함

- 전압 신호(0\~10V)는 전선 길이가 길어지면 전압 강하나 외부 노이즈의 영향을 받기 쉬워.
- 전류 신호(4\~20mA)는 전선 저항이 달라져도 전류를 일정하게 유지하기 때문에 비교적 안정적이야.

### 2. 0mA와 4mA를 구분할 수 있음

가장 중요한 이유 중 하나야.

- 4mA = 측정값의 최솟값(0%)
- 20mA = 측정값의 최댓값(100%)
- 0mA = 전선 단선 또는 전원 이상 가능성

즉, 정상적인 측정값의 시작을 0mA가 아닌 4mA로 설정해서 고장 여부를 쉽게 판단할 수 있어.

### 3. 장거리 전송에 유리함

공장이나 산업 현장에서는 센서와 제어 장치(PLC) 사이의 거리가 멀어.

4\~20mA는 긴 케이블을 사용해도 신호를 비교적 정확하게 전달할 수 있어.

### 4. 전력 공급과 신호 전달을 동시에 할 수 있음

2선식 센서는 하나의 전류 루프를 통해 전원을 공급받으면서 측정 신호도 전달할 수 있어.

이를 \*\*루프 전원 방식(Loop Powered)\*\*이라고 해.

### 5. 산업 표준으로 널리 사용됨

오랫동안 산업 자동화 분야에서 검증되고 표준화되어 여러 제조사의 센서와 PLC를 쉽게 연결할 수 있어.

쉽게 말하면, 아날로그 입력값(전압)을 디지털 숫자로 변환한 결과를 저장하는 공간이야.
