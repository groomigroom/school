아마 이전에 가상환경 생성 명령어를 입력하실 때 다른 폴더에서 만들어졌거나, 생성이 제대로 완료되지 않았을 확률이 높습니다.

## 💡 해결 방법 (순서대로 한 줄씩 입력하세요)
1. 가상환경 새로 만들기
현재 폴더 안에 venv라는 이름의 가상환경 폴더를 생성합니다. (입력 후 몇 초간 아무 반응이 없다가 다음 줄로 넘어가면 성공입니다.)

python -m venv venv

2. 권한 임시 허용하기
Windows 스크립트 실행 보안을 임시로 해제합니다.

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

3. 가상환경 활성화하기
이제 정상적으로 만들어진 가상환경을 켭니다.

.\venv\Scripts\Activate.ps1

------------------------------
## 🔍 정상 작동 확인

가상환경이 켜진 것을 확인한 후, 이어서 pip install streamlit을 입력해 설치를 진행하시면 됩니다.
