# 단과대학 학사 관리 시스템 – 학생정보관리

학생정보관리는 학생의 기본정보를 등록하고, 조회·수정·삭제하는 기능을 담당한다. 이를 자료흐름도(DFD) 와 소단위명세서(Mini Specification) 로 표현하면 다음과 같다.

## 1. 자료흐름도(DFD)

### ① 배경도(Context Diagram)

학생 / 학사 담당자

학생정보 입력 및 조회 요청

0\. 학생정보관리 시스템

학생 / 학사 담당자

등록 결과, 학생정보, 처리 결과

### ② 레벨 0 자료흐름도

[학생]

학생정보 등록 요청 / 본인정보 조회 요청

1.0 학생정보 등록

D1. 학생정보 파일

학번, 이름, 학과, 연락처, 주소 등

[학사 담당자]

학생정보 조회 / 수정 / 삭제 요청

2.0 학생정보 조회·수정·삭제

D1. 학생정보 파일

학생정보 읽기 및 변경사항 저장

[학사 담당자]

조회 결과 / 수정 결과 / 삭제 결과

참고: 위 도식은 과제 작성을 위한 개념적 표현이다. 자료흐름도의 표준 기호로 그릴 때는 외부 개체는 사각형, 처리 과정은 원 또는 둥근 기호, 자료 저장소는 평행선 형태로 표시하면 된다.

## 2. 소단위명세서(Mini Specification)

소단위명세서는 자료흐름도의 각 처리 과정이 어떤 절차로 수행되는지 상세하게 기술한 것이다.

### 처리 1.0 — 학생정보 등록

| 항목   | 내용                          |
| ---- | --------------------------- |
| 처리명  | 학생정보 등록                     |
| 입력자료 | 학생정보 등록 신청서                 |
| 출력자료 | 등록 결과 메시지                   |
| 처리내용 | 1. 학생정보를 입력받는다.             |
|      | 2. 필수 항목의 입력 여부를 확인한다.      |
|      | 3. 학번 중복 여부를 확인한다.          |
|      | 4. 입력값이 유효하면 학생정보 파일에 저장한다. |
|      | 5. 등록 성공 또는 오류 메시지를 출력한다.   |

### 처리 2.0 — 학생정보 조회

| 항목   | 내용                          |
| ---- | --------------------------- |
| 처리명  | 학생정보 조회                     |
| 입력자료 | 학번 또는 검색 조건                 |
| 출력자료 | 학생정보 조회 결과                  |
| 처리내용 | 1. 학번 또는 검색 조건을 입력받는다.      |
|      | 2. 학생정보 파일에서 해당 학생을 검색한다.   |
|      | 3. 검색 결과가 있으면 학생정보를 출력한다.   |
|      | 4. 검색 결과가 없으면 안내 메시지를 출력한다. |

### 처리 3.0 — 학생정보 수정

| 항목   | 내용                         |
| ---- | -------------------------- |
| 처리명  | 학생정보 수정                    |
| 입력자료 | 학번, 변경할 학생정보               |
| 출력자료 | 수정 결과 메시지                  |
| 처리내용 | 1. 수정할 학생의 학번을 입력받는다.      |
|      | 2. 학생정보 파일에서 해당 학생을 검색한다.  |
|      | 3. 학생이 존재하면 변경할 정보를 입력받는다. |
|      | 4. 변경된 정보를 저장한다.           |
|      | 5. 수정 결과를 출력한다.            |

### 처리 4.0 — 학생정보 삭제

| 항목   | 내용                        |
| ---- | ------------------------- |
| 처리명  | 학생정보 삭제                   |
| 입력자료 | 삭제할 학생의 학번                |
| 출력자료 | 삭제 결과 메시지                 |
| 처리내용 | 1. 삭제할 학생의 학번을 입력받는다.     |
|      | 2. 학생정보 파일에서 해당 학생을 검색한다. |
|      | 3. 학생이 존재하는지 확인한다.        |
|      | 4. 삭제 권한 및 삭제 여부를 확인한다.   |
|      | 5. 학생정보를 삭제하고 결과를 출력한다.   |

## 3. 정리

- 자료흐름도: 학생정보관리 시스템의 입력자료, 처리 과정, 자료 저장소, 출력자료 사이의 흐름을 표현한다.
- 소단위명세서: 학생정보 등록·조회·수정·삭제 각 처리 과정의 구체적인 알고리즘과 업무 규칙을 설명한다.

과제 제출용이라면 위의 레벨 0 자료흐름도와 처리 1.0\~4.0 소단위명세서를 함께 작성하면 학생정보관리 기능을 비교적 체계적으로 나타낼 수 있다.
