### 1. 5V를 사용하는 이유

1. 전원 공급 전압(VCC): ATmega128A는 5V 전원으로 구동할 수 있어.
2. 디지털 신호 기준: 5V를 공급하면 HIGH 신호는 일반적으로 5V에 가까운 전압으로 표현돼.

### 2. ADC에서 5V가 의미하는 것

ATmega128A의 ADC는 10비트이므로 총 1,024단계(0\~1023)로 전압을 구분해.

기준 전압을 5V로 설정하면 다음과 같아.

| 입력 전압 | ADC 변환값 |
| ----- | ------- |
| 0V    | 0       |
| 1V    | 약 205   |
| 2V    | 약 409   |
| 3V    | 약 614   |
| 4V    | 약 818   |
| 5V    | 1023    |

계산 공식은 다음과 같아.

\\[ ADC=\frac{V\_{in}}{V\_{ref}}\times1023 \\]

### 3. 핵심 정리

- VCC: 마이크로컨트롤러에 공급하는 전원 전압
- AVCC: ADC 및 아날로그 회로에 공급하는 전원

- ADC: 아날로그 전압을 0\~1023의 디지털 값으로 변환
