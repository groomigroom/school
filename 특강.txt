스프링부트(Spring Boot) 서버를 구축하는 과정을 시뮬레이션하는 텍스트 타이쿤 게임(Spring Boot Tycoon)의 기본 설계도입니다.

🎮 게임 개요: [스프링부트 타이쿤: 서버를 지켜라!]

• 장르: 시뮬레이션 / 코딩 타이쿤
• 목표: 트래픽 폭주나 에러를 막고 안정적인 REST API 서버를 운영하기
• 자원: 개발력(Java), 메모리(RAM), 커피(☕), 트래픽 처리량(TPS)

🏗️ 게임 진행 단계


1단계: 프로젝트 생성 (Spring Initializr)

• 선택지:
	• Java 버전: Java 17 또는 Java 21 선택 (잘못 고르면 빌드 실패 페널티)
	• Dependencies(의존성):
		• Spring Web: 기본 API 구축용 (필수)
		• Spring Data JPA: 데이터베이스 연동 (선택 시 개발 속도 증가, 메모리 사용량 증가)
		• Spring Security: 보안 강화 (초반에 넣으면 로그인 구현 퀘스트 발동)

2단계: 엔티티(Entity) 및 DB 설계

• 미션: 회원가입 및 로그인 테이블 설계하기
• 이벤트 발생:
	• "누군가 비밀번호를 평문(Plain Text)으로 저장하라고 합니다!"
	• 선택 A: 그냥 저장한다 -> [보안 취약점] 해킹 이벤트 발생 (게임 오버 확률 UP)
	• 선택 B: BCryptPasswordEncoder로 암호화한다 -> 안전하게 통과 (+개발력 소모)

3단계: API 구현 및 테스트

• 미션: GET /api/v1/users 엔드포인트 만들기
• 발생하는 에러 (랜덤 이벤트):
	• NullPointerException (NPE): 객체 초기화를 안 해서 서버가 멈췄습니다. Optional을 써서 방어 코드를 작성하세요!
	• OutOfMemoryError: 리스트를 페이징 처리(Paging) 없이전체 조회(selectAll)해서 메모리가 터졌습니다. .getPage()를 적용해야 합니다.

4단계: 트래픽 부하 테스트 (JMeter / K6 시뮬레이션)

• 상황: 갑자기 서비스가 실검에 올라 동시 접속자 10,000명이 몰립니다.
• 해결책:
	• 커넥션 풀(HikariCP) 크기 늘리기
	• Redis 캐시 도입하기
	• Nginx 앞단에 두기

💻 간단한 콘솔 프로토타입 (Java 코드 예시)

직접 실행해볼 수 있는 간단한 텍스트 기반 서버 시뮬레이션 코드입니다.
java
import java.util.Scanner;

public class SpringBootTycoon {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int memory = 512; // MB
        int tps = 100;
        int day = 1;

        System.out.println("=== 스프링부트 서버 운영을 시작하겠습니다 ===");

        while (memory > 0) {
            System.out.println("\n[Day " + day + "] 현재 메모리: " + memory + "MB | 처리 가능 TPS: " + tps);
            System.out.println("1. JPA 연관관계 설정하기 (N+1 문제 위험!)");
            System.out.println("2. Redis 캐시 도입하기 (메모리 -128MB, TPS +200)");
            System.out.println("3. 그냥 운영하기 (트래픽 모니터링)");
            System.out.print("선택하세요: ");

            int choice = scanner.nextInt();
            if (choice == 1) {
                System.out.println("⚠️ N+1 쿼리 폭탄 발생! DB 부하로 TPS가 반토막 납니다.");
                tps /= 2;
            } else if (choice == 2) {
                memory -= 128;
                tps += 200;
                System.out.println("⚡ 캐시 적용 완료! 응답 속도가 빨라졌습니다.");
            } else {
                System.out.println("평화로운 하루였습니다.");
            }

            day++;
            if (day > 5) {
                System.out.println("🎉 축하합니다! 5일 동안 서버가 터지지 않았습니다!");
                break;
            }
        }
        if (memory <= 0) {
            System.out.println("💥 OutOfMemoryError 발생! 서버가 다운되었습니다.");
        }
        scanner.close();
    }
}

@Configuration
public class SecurityConfig {

    // 시큐리티 필터 구획을 내 마음대로 커스텀
    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) {

        // 수많은 필터 중 CSRF 필터를 disable 시킴
        http
                .csrf(csrf -> csrf.disable());

        // 경로별 인가
        http
                .authorizeHttpRequests(auth -> auth
                        .requestMatchers("/**").permitAll())
                ;

        // 세션 설정 STATELESS
        http
                .sessionManagement(session -> session
                        .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
                );

        // 최종 빌드
        return http.build();
    }

}

private final SecretKey key;
private final long accessTokenExpireTime;

public JWTUtil(
        @Value("${jwt.secret}") String secret,
        @Value("${jwt.access-token-expire-time}") long accessTokenExpireTime
) {
    this.key = Keys.hmacShaKeyFor(
            secret.getBytes(StandardCharsets.UTF_8)
    );
    this.accessTokenExpireTime = accessTokenExpireTime;
}

public String createAccessToken(String username, String role) {

    Date now = new Date();
    Date expireDate = new Date(now.getTime() + accessTokenExpireTime);

    return Jwts.builder()
            .subject(username)
            .claim("role", role)
            .claim("tokenType", "ACCESS")
            .issuedAt(now)
            .expiration(expireDate)
            .signWith(key)
            .compact();
}
