커피숍 매장관리 프로그램을 \*\*구조 패턴(Structural Pattern)의 Adapter 패턴(어댑터 패턴)\*\*을 적용하여 설계해 보겠습니다.

과제 제출용으로 활용할 수 있도록 클래스 다이어그램과 패턴 적용 클래스명, 실제 사용 예시까지 정리하겠습니다.

# 1. 프로그램 개요

프로그램명: Adapter 패턴을 활용한 커피숍 매장관리 프로그램

커피숍에서 사용하는 여러 외부 시스템을 하나의 공통 인터페이스로 연결하여 관리하는 프로그램입니다.

주요 기능은 다음과 같습니다.

- 커피 메뉴 관리
- 주문 및 결제 관리
- 재고 관리
- 매출 관리
- 외부 결제 시스템 연동 (카드, 카카오페이 등)

Adapter 패턴 적용 목적

카드 결제 시스템이나 간편결제 시스템은 각각 사용 방법과 메서드가 다릅니다. 이를 Adapter 클래스를 통해 공통 결제 인터페이스로 통일합니다.

# 4. Java 코드 예시

전자정부표준프레임워크에서도 사용할 수 있는 일반적인 Java 객체지향 구조입니다.

① Target - Payment.java

java

```java
public interface Payment {
    boolean pay(int amount);
}
```

② Adaptee - CardPayment.java

java

```java
public class CardPayment {

    public boolean cardPay(int price) {
        System.out.println("카드 결제 금액: " + price);
        return true;
    }
}
```

③ Adaptee - KakaoPayment.java

java

```java
public class KakaoPayment {

    public boolean kakaoPay(int money) {
        System.out.println("카카오페이 결제 금액: " + money);
        return true;
    }
}
```

④ Adapter - PaymentAdapter.java

java

```java
public class PaymentAdapter implements Payment {

    private CardPayment cardPayment;
    private KakaoPayment kakaoPayment;

    public PaymentAdapter(CardPayment cardPayment) {
        this.cardPayment = cardPayment;
    }

    public PaymentAdapter(KakaoPayment kakaoPayment) {
        this.kakaoPayment = kakaoPayment;
    }

    @Override
    public boolean pay(int amount) {

        if (cardPayment != null) {
            return cardPayment.cardPay(amount);
        }

        if (kakaoPayment != null) {
            return kakaoPayment.kakaoPay(amount);
        }

        return false;
    }
}
```

⑤ Client - OrderService.java

java

```java
public class OrderService {

    private Payment payment;

    public OrderService(Payment payment) {
        this.payment = payment;
    }

    public void processOrder(int amount) {

        boolean result = payment.pay(amount);

        if (result) {
            System.out.println("주문 및 결제 완료");
        } else {
            System.out.println("결제 실패");
        }
    }
}
```

⑥ 실행 예시 - Main.java

java

```java
public class Main {

    public static void main(String[] args) {

        // 카드 결제
        Payment card = new PaymentAdapter(
            new CardPayment()
        );

        OrderService order1 = new OrderService(card);
        order1.processOrder(4500);

        // 카카오페이 결제
        Payment kakao = new PaymentAdapter(
            new KakaoPayment()
        );

        OrderService order2 = new OrderService(kakao);
        order2.processOrder(5000);
    }
}
```

text

```text

카카오페이 결제 금액: 5000
주문 및 결제 완료
```

# 5. Adapter 패턴 적용 효과

| 구분 | 설명 |
| --- | --- |
| 호환성 | 서로 다른 결제 시스템을 공통 인터페이스로 사용 |
| 확장성 | 새로운 결제 시스템 추가가 쉬움 |
| 유지보수 | 외부 결제 시스템 변경 시 Adapter 수정으로 대응 가능 |
| 재사용성 | 기존 결제 시스템을 수정하지 않고 활용 가능 |

작성

## Adapter 패턴을 활용한 커피숍 매장관리 프로그램

### 1\. 설계 목적

커피숍 매장관리 프로그램에서 사용하는 다양한 외부 결제 시스템을 효율적으로 연동하기 위해 구조 패턴 중 Adapter 패턴을 적용하였다.

### 2\. 패턴 적용 방법

Adapter 패턴은 서로 호환되지 않는 인터페이스를 가진 클래스들이 함께 동작할 수 있도록 중간에서 인터페이스를 변환해 주는 디자인 패턴이다.

본 프로그램에서는 카드 결제 시스템과 카카오페이 시스템의 결제 메서드가 서로 다르기 때문에 PaymentAdapter 클래스를 구현하였다.

### 3\. 패턴 적용 클래스

- Client: OrderService
- Target: Payment
- Adapter: PaymentAdapter
- Adaptee: CardPayment
- Adaptee: KakaoPayment

### 4\. 적용 사례

고객이 커피를 주문하고 결제 수단으로 카드 또는 카카오페이를 선택하면 OrderService가 Payment 인터페이스를 통해 결제를 요청한다.

PaymentAdapter는 선택된 결제 시스템에 맞게 메서드를 변환하여 실제 결제를 처리한다.

### 5\. 기대 효과

서로 다른 결제 시스템을 동일한 인터페이스로 관리할 수 있으며, 향후 새로운 결제 수단이 추가되더라도 기존 주문 처리 코드를 크게 변경하지 않고 확장할 수 있다.

과제에서 가장 중요한 부분은 `PaymentAdapter`가 Adapter 역할이라는 점을 명확하게 표현하는 것입니다.

위 설계는 Adapter 패턴의 역할을 분명하게 보여주며, 실제 커피숍 매장관리 프로그램으로 확장하기에도 적합한 구조입니다.
