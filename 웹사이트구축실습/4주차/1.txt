모듈은 작은 기능 단위로 쪼개놓은 거

코드 재탕 느낌

common js 모듈
require()
module.exports

ES 모듈
import
export

이름 다르게 여러군데에서 받는거

여러가지 모듈들 불러와서 사용 가능함.

const hello = require("./hello");

노드 코어 모듈들
fs 파일 시스템
http
path 경로

위에 3가지 많이 쓴다.

streams 스트림
crypto 암호화
os 운영체제
util 유틸리티
events 이벤트

글로벌 모듈은 require 없이 사용할 수 있는 모듈
예시로는
global.console.log()

이걸 생략해서
console.log()
