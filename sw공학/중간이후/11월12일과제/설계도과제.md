# 3. 아키텍처 설계의 핵심 특징

① 확장성 (Scalability)

- 이용자가 증가하면 서버를 추가하여 처리 능력을 높일 수 있다.
- 상품 검색이나 주문처럼 사용량이 많은 기능만 별도로 확장할 수 있다.
- 로드 밸런서를 통해 사용자 요청을 여러 서버에 분산한다.

② 유지보수성 (Maintainability)

- 각 기능을 독립적인 서비스로 분리한다.
- 결제 서비스 수정 시 회원 서비스나 상품 서비스에 미치는 영향을 최소화한다.
- 서비스별로 독립적인 개발과 배포가 가능하다.

③ 안정성 (Reliability)

- 특정 서비스에 장애가 발생해도 다른 서비스에 미치는 영향을 줄인다.
- 데이터 백업 및 복구 체계를 구축한다.
- 결제 처리 과정에서 중복 결제가 발생하지 않도록 관리한다.

④ 데이터 관리

- 서비스별 데이터베이스를 분리하여 데이터 간 결합도를 낮춘다.
- 주문 및 결제와 같은 주요 데이터는 트랜잭션과 이벤트 처리를 통해 일관성을 관리한다.

# 4. 주요 기능의 처리 흐름

온라인 쇼핑몰의 상품 구매 과정

1. 회원가입 및 로그인

   고객 정보를 확인하고 로그인한다.
2. 상품 검색

   상품 서비스에서 원하는 상품을 검색한다.
3. 장바구니 관리

   원하는 상품을 장바구니에 추가한다.
4. 주문 생성

   주문 서비스에서 주문 정보를 생성한다.
5. 결제 처리

   결제 서비스가 외부 PG 시스템과 연동하여 결제를 진행한다.
6. 배송 처리

   결제가 완료되면 배송 서비스에서 배송 정보를 관리한다.
7. 주문 내역 및 배송 조회

   고객이 주문 내역과 현재 배송 상태를 확인한다.

# 5. 최종 설계 요약 (과제 제출용)

본 온라인 쇼핑몰은 마이크로서비스 아키텍처(MSA)를 적용하여 설계하였다.

시스템을 회원, 상품, 장바구니, 주문, 결제, 배송, 주문 내역 등의 독립적인 서비스로 분리하고 API Gateway를 통해 사용자 요청을 각 서비스에 전달하도록 구성하였다.

각 서비스는 독립적인 데이터베이스를 사용하여 데이터 간 결합도를 낮추고, 외부 결제 시스템 및 택배사 시스템과 연동하도록 설계하였다.

또한 이용자 증가에 따라 필요한 서비스만 개별적으로 서버를 확장할 수 있도록 하였으며, 특정 서비스의 수정이나 장애가 다른 서비스에 미치는 영향을 최소화하여 확장성, 유지보수성, 안정성을 확보하는 것을 목표로 하였다.
