머신러닝은 예측해서 결과를 때려 맞추는 거다.

훈련과 학습이 중요

목적으로 하는 값을 빨리 쓰는가?

데이터 과적합이 잘못된 답지를 많이 줬을 때 생기는거??

하이퍼파라미터(초매개변수) : 모델의 성능에 영향을 주는 사람이 값을 지정하는 변수.
매개변수 : 가중치와 편향. 학습을 하는 동안 값이 계속해서 변하는 수.

인공지능이 하는게 가중치를 구하는거


인공지능(특히 머신러닝과 딥러닝)에서 가중치(Weight)와 편향(Bias)은 인공신경망이 데이터를 학습하고 예측을 내리는 데 사용하는 핵심적인 수학적 매개변수(파라미터)입니다.
쉽게 비유하자면, 가중치는 "각 조건의 중요도"이고 편향은 "기본적인 성향이나 고집"이라고 볼 수 있습니다.
------------------------------
## 1. 가중치 (Weight, $W$)
가중치는 입력 데이터가 결과에 미치는 영향력의 크기(중요도)를 나타냅니다.

* 수학적 역할: 입력 값($X$)에 가중치($W$)를 곱합니다 ($W \times X$).
* 쉽게 이해하기: 우리가 어떤 중고차의 가격을 예측한다고 가정해 봅시다. 입력 조건으로 '주행거리'와 '차량 색상'이 있다면, 가격을 결정할 때 '주행거리'가 훨씬 중요한 조건일 것입니다. 이때 인공지능은 학습을 통해 '주행거리'에는 큰 가중치를 부여하고, '차량 색상'에는 작은 가중치를 부여합니다.

## 2. 편향 (Bias, $b$)
편향은 입력 값과 상관없이 결과에 더해지는 기본값(예측의 기준선)입니다.

* 수학적 역할: 가중치가 곱해진 값들에 마지막으로 편향을 더합니다 ($W \times X + b$).
* 쉽게 이해하기: 어떤 중고차가 주행거리가 0km이고 옵션이 전혀 없더라도, 차 자체의 '기본 고철 값'이나 '브랜드 기본가'가 존재합니다. 입력 데이터($X$)가 모두 0일 때도 결과가 항상 0이 되지 않도록 조절해 주는 정수기(수도꼭지)의 기본 수압 같은 역할을 합니다. 모델이 한쪽으로 쉽게 치우치지 않거나, 반대로 특정 기준을 쉽게 넘을 수 있도록 조절해 줍니다.

------------------------------
## 직관적인 비교 테이블

| 구분 | 가중치 (Weight) | 편향 (Bias) |
|---|---|---|
| 비유 | 각 조건의 중요도 / 가중치 | 모델의 기본 성향 / 민감도 |
| 수학적 연산 | 입력값에 곱해지는 수 ($W \times X$) | 결과에 더해지는 수 ($+ b$) |
| 기능 | 그래프의 기울기를 조절함 | 그래프를 위아래로 이동(시프트)시킴 |
| 목적 | 어떤 변수가 정답에 더 큰 영향을 주는지 파악 | 입력값이 0이거나 약할 때도 올바른 판단을 내리도록 보정 |

## 요약하자면
인공지능이 "학습을 한다"는 것은 수많은 데이터를 반복해서 보며 정답을 가장 잘 맞히는 최적의 가중치($W$)와 편향($b$)의 조합을 찾아가는 과정을 의미합니다. 이 두 값이 정교하게 조정되어야만 인공지능이 새로운 데이터를 받았을 때 정확한 예측이나 분류를 할 수 있습니다.
