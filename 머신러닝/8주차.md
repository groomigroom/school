1. 이진 크로스 엔트로피 (Binary Cross-Entropy, BCE)
• 사용 목적: 출력해야 할 정답(클래스)이 2개인 [이진 분류(Binary Classification)] 문제 (예: 스팸 메일 여부, 합격/불합격)
• 특징:
	• 신경망의 마지막 출력층 활성화 함수로 주로 시그모이드(Sigmoid) 함수를 사용합니다.
	• 출력값이 0과 1 사이의 확률값으로 나오며, 각 독립된 두 개의 사건(참 또는 거짓)에 대한 오차를 각각 계산합니다.
2. 범주형 크로스 엔트로피 (Categorical Cross-Entropy, CCE)
• 사용 목적: 정답(클래스)이 3개 이상인 [다중 클래스 분류(Multi-class Classification)] 문제
• 특징:
	• 정답 레이블이 원-핫 인코딩(One-Hot Encoding) 형태로 제공될 때 사용합니다. (예: 정답이 두 번째 클래스라면 [0, 1, 0])
	• 마지막 출력층의 활성화 함수로 소프트맥스(Softmax) 함수를 사용하여 전체 클래스에 대한 확률 분포를 출력하고 이를 비교합니다.
3. 스파스 범주형 크로스 엔트로피 (Sparse Categorical Cross-Entropy, SCCE)
• 사용 목적: 정답(클래스)이 3개 이상인 [다중 클래스 분류] 문제
• 특징:
	• 범주형과 달리 정답 레이블이 원-핫 인코딩이 아닌 정수(Integer) 형태 (1, 2, 3 등)로 주어질 때 사용합니다.
	• 별도로 원-핫 인코딩 변환 작업을 거칠 필요가 없어, 클래스 개수가 매우 많을 때 메모리와 연산 과정을 절약할 수 있습니다.
