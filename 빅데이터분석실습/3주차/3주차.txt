맥(Mac) 환경에서 미니콘다(Miniconda)를 사용 중이시라면, 터미널(Terminal) 앱을 열고 현재 주피터 노트북이 실행 중인 가상환경에 라이브러리를 설치해야 합니다.
가장 확실하고 안전한 2가지 설치 방법을 알려드릴게요.
------------------------------
## 방법 1: 주피터 노트북 셀에서 바로 설치하기 (가장 추천)
현재 열려 있는 주피터 노트북의 셀에 아래 명령어를 입력하고 실행(Shift + Enter)하세요. 맥의 미니콘다 환경을 자동으로 인식하여 올바른 경로에 설치해 줍니다.

!conda install -y openpyxl


* 만약 conda 설치가 너무 오래 걸리거나 오류가 난다면 아래 명령어로 시도해 보세요.

!pip install openpyxl

------------------------------
## 방법 2: 맥 터미널(Terminal) 앱에서 설치하기
주피터 노트북 밖에서 직접 설치하고 싶다면 다음과 같이 진행합니다.

   1. 맥의 터미널(Terminal) 앱을 엽니다. (단축키: Command + Space 실행 후 '터미널' 검색)
   2. 주피터 노트북을 실행할 때 사용하는 가상환경을 활성화합니다. (기본 환경이라면 base)
   
   conda activate 가상환경이름
   
   (예: conda activate base 또는 본인이 만든 환경 이름)
   3. 활성화된 상태에서 아래 명령어를 입력해 설치합니다.
   
   conda install openpyxl
   
   *(중간에 Proceed ([y]/n)?가 나오면 **y*를 누르고 엔터를 치시면 됩니다.)

------------------------------
## 설치 후 확인하기
설치가 완료되었다면 주피터 노트북으로 돌아가 코드를 다시 실행해 보세요.

import openpyxl
print(openpyxl.__version__)

만약 터미널에서 설치했는데도 노트북에서 여전히 ModuleNotFoundError가 뜬다면, 주피터 노트북이 커널을 잘못 잡고 있는 것일 수 있습니다. 혹시 현재 사용 중이신 별도의 가상환경 이름이 있으신가요? 오류가 계속된다면 알려주세요!
